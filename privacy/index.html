Wanted By Chat Publisher: Privacy Policy

Last updated: November 11, 2026

Wanted By Chat Publisher ("the tool") is a private publishing tool operated by the owner of the gaming channel Wanted By Chat (youtube.com/@wantedbychat, instagram.com/wantedbychat, tiktok.com/@wanted.by.chat). It is used only by the channel's own team to publish and manage the channel's own videos on the channel's own accounts. It is not offered to the public and does not let anyone else sign in.

What it accesses

With the account owner's permission, the tool uses:

  • YouTube Data API and YouTube Analytics API (Google OAuth): upload, schedule and update videos and thumbnails on the authorized channel, and read view counts and analytics for those videos.
  • Instagram API (Meta): publish Reels to the authorized Instagram account and read basic account information (username, ID).
  • TikTok Login Kit and Content Posting API: read basic profile information of the authorized TikTok account (display name, avatar, open ID) and upload or publish videos to that account.

The tool does not access data belonging to any other user, account or channel, and it does not read private messages, followers' personal data or contacts.

How data is stored

Access tokens, video files and video statistics are stored only on the operator's own server and computer, protected so only the operator can read them. They are not sold, shared with third parties, or used for advertising or profiling.

Retention and deletion

Video files are deleted from the server after publishing and measurement (typically within 3 days). Tokens are kept until access is revoked. The operator deletes any stored data on request.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy (https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

Revoking access

  • Google/YouTube: https://myaccount.google.com/permissions
  • Instagram/Meta: Instagram Settings > Website permissions > Apps and websites
  • TikTok: TikTok Settings > Security and permissions > Manage app permissions
